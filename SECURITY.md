# Security policy

## Reporting a vulnerability

Please report security problems privately. On this repository's **Security** tab, click **Report a vulnerability** and describe the problem and how to reproduce it. Do not open a public issue for a security problem.

This is a one-person project, so there is no promised response time. Reports are read and answered as soon as possible.

## In scope

- How the app stores, reads and sends your OpenRouter API key.
- How the app handles the text it reads from other apps: the selection it captures, the clipboard it saves and restores, the text it sends to OpenRouter, and the history it keeps on disk.

Problems in OpenRouter itself, in the AI models, or in macOS are out of scope. Please report those to their owners.
